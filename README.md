Todo Application

A simple Todo application built using Spring Boot to manage daily tasks.

Features
- Add new tasks
- View all tasks
- Mark tasks as completed or pending
- Delete tasks

Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Thymeleaf
- Bootstrap

How to Run
1. Clone this repository.
2. Configure your MySQL database credentials in `application.properties`.
3. Run the Spring Boot application.
4. Open `http://localhost:8080` in your browser.
